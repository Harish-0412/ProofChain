# Phase 2: Sample Dataset Creation

## Goal

Create realistic evidence data for testing and demonstrating ProofChain.

The dataset must be good enough to trigger the MVP rules and support one complete demo story from evidence ingestion to audit package generation.

---

# 1. Completed Dataset Scope

The generated sample dataset includes:

- Five department folders
- Five accreditation requirements
- Event report PDFs
- Attendance spreadsheets
- Approval document PDFs
- Certificate PDFs
- Photo evidence PNGs
- Injected error manifest
- Dataset manifest
- Expected extraction output

All names and records are fictional, but they use realistic modern South Indian naming patterns.

---

# 5. Injected Problems

The dataset intentionally includes:

| Problem | Purpose |
|---|---|
| Count mismatch | Tests participant reconciliation |
| Missing approval | Tests required evidence checklist |
| Missing signature | Tests approval completeness |
| Duplicate report | Tests checksum duplicate detection |
| Duplicate student rows | Tests attendance deduplication |
| Wrong academic year | Tests date validation |
| Wrong department | Tests department consistency |
| Incorrect mapping | Tests evidence mapping review |
| Duplicate photo | Tests duplicate media detection |

---

# 6. Main Demo Story

Primary demo case:

```text
Department: CSE
Requirement: C3.2.1
Claim: 120 students attended an Agentic AI industry workshop.
```

Expected findings:

- Event report says 120 participants.
- Attendance sheet has 108 unique students.
- Attendance sheet includes duplicate student rows.
- Approval document exists but has no signature.
- Duplicate event report exists.

This gives ProofChain enough signal to show extraction, contradiction detection, duplicate detection, task generation, and approval workflow.

# 7. Important Dataset Files

## Dataset Manifest

```text
sample_data/dataset_manifest.json
```

This file lists departments, requirements, events, counts, expected approvals, and generated file paths.

## Injected Error Manifest

```text
sample_data/injected_errors/injected_errors_manifest.json
```

This file lists all deliberately planted dataset problems.

## Expected Extraction Results

```text
sample_data/extraction_outputs/expected_extraction_results.json
```

This file contains the expected extracted values for event report PDFs.

## Actual Extraction Results

```text
sample_data/extraction_outputs/extracted_fields.json
```

This file is generated by the Phase 3 extraction script.
